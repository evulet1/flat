# RentBoard

A property management MVP for short-term rental owners. 

## Motivation
As an owner of short-term rental properties, I faced the pain of managing bookings, calendars, and communications across different platforms. I am building RentBoard to solve these problems, combining my 6+ years of frontend experience with my deep understanding of the hospitality domain.

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase (Coming soon)

## Features
- [x] Apartment Card UI component
- [ ] Authentication (Supabase)
- [ ] CRUD operations for properties
- [ ] AI-powered guest assistant (OpenAI)
